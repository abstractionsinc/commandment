# Commands

Command hierarchy, lexical aliases, command shortcuts, default relationships, and command-provider-produced commands.

- [Nested commands](nested/) - Build a natural hierarchy of commands and subcommands.
- [Lexical aliases](aliases/) - Give one command more than one recognized name without creating another command.
- [Command shortcuts](shortcuts/) - Publish a convenience entry that targets a canonical command and supplies bounded fixed input.
- [Default relationship](default/) - Select a natural child command when its parent is invoked without another subcommand.
- [Command provider](dynamic/) - Publish invocation-dependent subcommands and use the accepted commands like ordinary commands.
