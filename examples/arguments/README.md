# Arguments

Positional input, alternate argument shapes, and forwarding another command after `--`.

- [Optional arguments](optional/) - Use an optional positional argument when omitting the operand has a natural meaning.
- [Argument forms](forms/) - Use alternate forms when one command has genuinely different positional shapes.
- [Pass-through arguments](pass-through/) - Keep everything after `--` untouched when forwarding another command.
